## ADDED Requirements

### Requirement: WG index for onboarding
The working groups index SHALL list all active WGs as cards with monogram, name, one-line focus, next meeting, and channel join links reachable within two taps.

#### Scenario: New member finds their WG
- **WHEN** a visitor opens the working groups index
- **THEN** every active WG shows a one-line focus statement and its join links (WhatsApp / group / drive) without login
