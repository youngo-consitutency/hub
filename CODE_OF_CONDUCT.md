# Code of conduct

Everyone should be able to contribute without harassment or discrimination. This applies to issues, pull requests, reviews, and other project spaces.

- Be respectful, especially when you disagree. Discuss the work, not the person.
- Welcome different backgrounds, experience levels, and English fluency.
- Give useful feedback and make room for questions.
- Respect privacy. Do not share someone’s personal information without permission.
- Do not post threats, discriminatory remarks, sexual harassment, spam, or repeated unwanted contact.

## When something goes wrong

For a public comment that breaks these rules, use its GitHub **Report content** menu to alert repository administrators. For threats, harassment, or private details that are unsafe to repeat here, use [GitHub’s abuse reporting process](https://docs.github.com/en/site-policy/acceptable-use-policies/github-community-guidelines#reporting-an-abuse-or-spam).

Do not repost harmful material or personal information in a public issue. Security reports have a separate [private reporting route](SECURITY.md).

Maintainers may edit or remove harmful content, warn a participant, limit participation, or block repeated or serious abuse. Decisions should consider the context and the people affected. These expectations also apply to maintainers.
